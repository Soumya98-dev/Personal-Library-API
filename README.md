## Models
```
Author
-------
id
name
country

Author
------
id          Required, unique, generated by DB
name        Required
country     Required

Book
-------
id
title
pages
published_year

```
**Entities**: Author, Book

```
    |------ Many Books
```

## The complete picture
```
Database

authors
+----+------------------+
| id | name             |
+----+------------------+
| 1  | George Orwell    |
+----+------------------+

books
+----+--------------+-----------+
| id | title        | author_id |
+----+--------------+-----------+
| 1  | 1984         |     1     |
+----+--------------+-----------+

              ▲
              │
       ForeignKey("authors.id")
              │
              ▼

SQLAlchemy

Book.author  ─────────────► Author object

Author.books ─────────────► List[Book]
```
